# 任务：把方向 A 宣传片改一版，让它讲清产品到底能干什么

## 背景

求职雷达（职达 / JobRadar）现在有两条宣传片：

- **方向 A**：`artifacts/promo/` —— 暖纸编辑部风、笔记本实景合成、慢推轨、卖气质。**你要改的是这条。**
- **方向 B**：`artifacts/promo-b/` —— 深色快剪、信息流向、卖功能。**别碰，另一条片子，有人在维护。**

A 现在的问题：**好看，但没说清产品能干什么**。它是一条气质片，观众看完不知道这产品解决什么问题。

---

## 必须改的：焦点

创始人定的两条核心价值，改完必须**两条都在片子里成为主干**（不是一闪而过的装饰）：

**① 快速可靠地筛选出「适合这个用户」的官方岗位链接**
- 国内 + 海外都支持
- 实习 / 校招 / 社招 都支持
- 关键差异：点开是**企业官网的岗位详情页**，不是第三方招聘平台的转载页

**② 提供职业洞察 = 行业信息差（岗位信息差、公司信息差）**
- 帮用户**选出最适合自己的那个岗位**
- 维度：时机 / 薪酬强度 / 路径 / 文化
- 这是产品的护城河，而 A 现在**完全没有出现**，这是最大的缺口

### ⛔ 不要讲的

**不要吹"我们抓了多少数据 / 覆盖多少个源 / 一晚探活多少个岗"。**

这条坑已经踩过并作废了一整版片子：那些数字是**我们的劳动量**，不是**用户的收益**。用户不关心我们跑了多少数据。工程师的自豪 ≠ 卖点。

覆盖广度可以讲，但必须换成**用户视角**：讲「你能找到的范围」（实习/校招/社招、国内/海外），不讲「我们抓了多少」。

## 技术铁律（全是踩过的坑，别重踩）

引擎的契约：`scene.html` 必须暴露 `window.__render(t)` / `window.__setSize(w,h)` / `window.__DUR`，
**画面是时间 t 的纯函数**。`render.py` 按帧把 t 喂进去、每帧等画完再截图，所以成片在数学上严格等间隔——
这就是"丝滑"的来源（不是靠录屏，录屏会掉帧，而且我们网页本身也不丝滑，录进去救不回来）。

1. **`scene.html` 里绝不能出现 `Math.random()`。** 每帧都会重掷骰子 → 成片全是雪花。
   所有"随机"必须由纯哈希从下标算：`h(i) = fract(sin((i+1)*127.1 + s*311.7) * 43758.5453)`
2. **不能用 CSS `animation` / `transition` / `requestAnimationFrame`。** 它们跟 wall-clock 走，
   逐帧渲染时会和 t 失步。一切位移/透明度都在 `__render(t)` 里按 t 算。
3. **逐字打字机效果不能直接切含 `<br>` 的整串** —— 会把 `<br>` 切成 `<b`。两行分开切。
4. **品牌字标那一行必须 `white-space:nowrap`。** 一换行整片气质当场崩。
5. **做"淘汰/塌陷"类动画时，必须先过"该不该淘汰"这道闸再套 transform**，
   否则该留下的元素也被一起压扁（我在 B 里踩过，3 个幸存者被压成了 3 条线）。
6. 中文字体没就位就截图，整片气质会掉档 —— 引擎已经等 `document.fonts.status === 'loaded'`，别绕过。

## 怎么做 / 怎么验收

```bash
cd artifacts/promo
python3 render.py --stills     # 先出 12 张关键帧自查，别直接渲全片
./build.sh                     # 出成片（要别的尺寸：./build.sh 2160 3840）
```

改完请自己过这几条：

- [ ] **两条价值各有一段独立、看得懂的内容**，不是一闪而过
- [ ] 找一个不懂这产品的人看完，能说出「它帮我找官方岗位」**和**「它告诉我该不该去」两句话
- [ ] 洞察那段带齐了 分级 + 时效 + 出处 + 去标识说明
- [ ] 画面里没有一行编造的公司×职位×城市，没有一句编造的洞察正文
- [ ] **A 还是暖纸浅色**，没被改成深色。自查：

```bash
ffmpeg -v error -i out/<成片>.mp4 -vf "fps=4,scale=64:114,format=gray" -f rawvideo - \
  | python3 -c "import sys;d=sys.stdin.buffer.read();print('平均亮度',sum(d)/len(d))"
```
  A 应该在 **200 以上**（B 是 28）。如果掉到 100 以下，说明 A 被改成深色了，和 B 撞了，回头改。

- [ ] 没有出现"我们抓了多少 / 探活多少"这类劳动量吹嘘
