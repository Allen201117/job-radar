## 1. 要对标的参考片（已拆解，直接用结论）

参考片是别人给 Claude 做的产品演示，21 秒、竖屏 720×1280、30fps。它的做法：

- **一台笔记本电脑放在虚化的办公室里**（落地窗 + 城市天际线，浅景深），UI 被合成贴到屏幕上。
- **屏幕里的 UI 不是录屏，是合成动画**。所以没有真实加载、没有卡顿、每一步都是理想时序。
- 镜头**全片不停地缓慢推进**（slow dolly / push-in），这是"丝滑"最大的来源。
- 节拍：logo 光晕绽开 → 字标逐字母显现 → Welcome 界面（输入框描边画出 + 四个功能 chip 错峰入场）→ 光标打字 → 模型下拉菜单错峰展开 → 回答逐行流入 → 一段大字动效（Motion / Motion Designer / Kreativ）→ 品牌落版。
- 每个元素都是「缓动 + 错峰（stagger）」入场，**没有任何东西是"啪"一下出现的**。

**"丝滑"的三个可复制机制（重点）**：
1. 镜头永远在动（哪怕没有元素在动，画面也在缓慢漂移）；
2. 所有入场都有 ease-out + 40~60ms 的错峰；
3. 时序是合成的理想值，不受真实加载速度影响。

## 2. 我们的产品是什么（宣传片必须讲对）

**职达 JobRadar** = 「公开企业官网岗位雷达看板」。核心闭环：

```
用户设置一次求职目标（岗位方向/城市/求职阶段/技能）
  → 系统持续抓取企业【官方招聘页】（不是第三方招聘平台的转载）
  → 逐条核验：还在招吗 / 对口吗 / JD 信息全吗
  → 只把「今天真正值得处理的」几条推给用户
  → 点开直接跳企业官网详情页
```

差异点（宣传片要传达的）：
- 数据来自**企业官方招聘页**，不是第三方转载页；
- **逐条探活**，失效岗位会被下架，不拿死岗充数；
- **宁缺毋滥**——今天没有对口的就明说没有，不硬凑（这是产品里真实存在的文案）。

## 5. 技术路线（关键：怎么做到"丝滑"）

我们自己的网页**加载和交互都没那么丝滑**，所以**不要去录屏真站点**。做法是**合成**：

**推荐做法（零新依赖，本机已具备）**：
1. 写一个自包含的 `scene.html`：把上面的 UI 用纯 HTML/CSS 复刻成几个场景。
2. **不用任何 CSS animation / transition / requestAnimationFrame**。
   暴露一个全局 `window.__render(t)`，它按时间 `t`（秒）**直接把 transform / opacity 写到元素上**。
   也就是说：**画面是 t 的纯函数**。
3. 用 **Python Playwright**（本机已装，chromium 已缓存）逐帧驱动：
   `for f in range(N): page.evaluate(f"window.__render({f/fps})"); page.screenshot(...)`
   机器再慢也只是渲染慢，成片在数学上严格等间隔 → **不可能掉帧**。
4. 用 **ffmpeg**（本机已装 `/opt/homebrew/bin/ffmpeg`）把帧序列编码成 MP4（H.264, yuv420p, faststart）。

**丝滑要点（照做）**：
- 镜头层（一个包住全部内容的 div）全程有缓慢的 `scale`+`translate` 关键帧，
  再叠一层极慢的正弦漂移（例如 `sin(t*0.42)*7px`），**让画面永远在动**。
- 缓动别用 linear。用 ease-out 三/四/五次，或首尾都平的钟形 `0.5-0.5*cos(PI*p)`。
- 列表/chip/卡片入场一律错峰 40~60ms。
- 入场同时带一点 `blur(10px)→0`，比单纯 opacity 高级很多。
- 想要真运动模糊：每输出帧多采样 2~3 次（快门角 50%），ffmpeg 用 `tmix=frames=N` 平均。
- 目标 **60fps**。

**输出规格**：竖屏 **1080×1920**（抖音/小红书/朋友圈），60fps，时长 **30~36 秒**，H.264 MP4。

**其他可选开源工具（如果你更熟，也可以用，但别为此装重型工具链）**：
- [Remotion](https://github.com/remotion-dev/remotion) — React 写视频、逐帧渲染 MP4（注意商用授权）
- [Motion Canvas](https://github.com/motion-canvas/motion-canvas) / [Revideo](https://github.com/redotvideo/revideo) — TS 程序化动效
- [tungs/timecut](https://github.com/tungs/timecut) + [timesnap](https://github.com/tungs/timesnap) — 劫持网页的时间函数（`Date.now`/`rAF`/`setTimeout`）后逐帧截图，**专治"网页动画录屏会掉帧"**，如果你想录真站点就用这个
- [Cap](https://github.com/CapSoftware/Cap) — 开源录屏，自带平滑变焦
