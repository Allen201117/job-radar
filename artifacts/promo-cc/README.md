# 职达 JobRadar 宣传片（合成版）

竖屏 1080×1920 / 60fps / 36s，H.264。产物在 `out/`。

```bash
bash artifacts/promo-cc/build.sh          # 出成片
SHUTTER=2 bash artifacts/promo-cc/build.sh  # 带运动模糊版（渲染时间翻倍）

python3 render.py --stills                # 只出 12 张等距关键帧，快速看效果
python3 render.py --stills --start 19 --end 25 --out s5win   # 看某一段
```

## 为什么不录屏

参考片（Claude 那条）看着丝滑，是因为**屏幕里的 UI 根本不是录屏，是合成动画**——
没有真实加载、没有网络等待，每一步都是理想时序。我们的网页交互和加载速度达不到那个水平，
录屏只会把卡顿如实记录下来。所以这里走同一条路：**把 UI 重新合成一遍**。

## 丝滑是怎么来的（三个机制）

1. **画面是时间的纯函数。**
   `scene.html` 里没有任何 CSS `animation` / `transition` / `requestAnimationFrame`。
   只暴露一个 `window.__render(t)`，它按秒数 `t` 直接把 `transform` / `opacity` 写到元素上。
   渲染器按帧把 `t` 喂进去、等页面画完再截图 —— 机器再慢也只是渲染慢，
   **成片在数学上严格等间隔，不可能掉帧**。

2. **摄影机全程不停。**
   所有内容包在 `#cam` 里，每个场景一个机位关键帧（scale + translate），
   之间用首尾都平的钟形缓动过渡，再叠一层极慢的正弦漂移
   （`sin(t*0.42)*7px` 之类）。哪怕某一拍没有元素在动，画面也在缓慢呼吸。

3. **没有任何东西是"啪"一下出现的。**
   入场统一 ease-out + 40~60ms 错峰 + `blur(10px)→0`；
   按钮按下、chip 选中、数字滚动都有明确的缓动曲线。

## 文件

| 文件 | 作用 |
|---|---|
| `scene.html` | 全部画面 + `render(t)`。自包含，可直接在浏览器里打开调 `__render(12.5)` 看某一帧 |
| `render.py` | Playwright 逐帧驱动 + 截图。`--stills` 快速审阅，`--shutter N` 多采样做运动模糊 |
| `build.sh` | 渲染 + ffmpeg 编码，跑完自动清帧 |

## 分镜（36s）

| 段 | 时间 | 内容 |
|---|---|---|
| S1 痛点 | 0–5.3s | 岗位流不断上滚刷不完 → 「每天几百个新岗位 / 刷不完，也挑不出来」 |
| S2 品牌 | 5.1–9.0s | 雷达环描边画出 + 扫描扇转 + 命中点 ping → `职达 JOBRADAR` 逐字显现 → 「每天替你看官网」 |
| S3 设置目标 | 8.8–14.1s | 光标打字填偏好，`社招` 变墨底、`AI`/`数据` 亮起 → 按下 `保存我的雷达` |
| S4 系统在跑 | 13.9–19.4s | 雷达涟漪 + 公司名沿轨道转、被扫到就发绿光 → 三个真数字滚动 → 「全部来自企业官方招聘页，不是第三方转载」 |
| S5 逐条核验 | 19.2–25.0s | 25 块岗位，三波盖章剔除 `已失效`/`不对口`/`信息不全` → 只剩 3 块发绿光聚拢 → 「宁可空着，也不硬凑」 |
| S6 今日机会 | 24.8–31.4s | 3 张真实岗位卡错峰升起 → 光标点 `官网详情` → 企业官网详情页飞入 → 「点开就是企业官网，不是转载页」 |
| S7 落版 | 31.2–36.0s | 品牌锁定 + 「每天替你看官网，只留下值得行动的机会。」+ `开始设置我的雷达 →` |

S5 活下来的三块（首字母 `字`/`百`/`腾`）就是 S6 的三张卡，叙事上接得住。

## 片里所有数字和岗位都是真的

2026-07-30 查生产库（香港 jobs 库）取的：

| 指标 | 真值 | 出处 |
|---|---|---|
| 在招岗位（有完整 JD 正文） | 307,661 | `count_valid_active_jobs()` |
| 企业官方招聘源（公司数） | 1,053 | `count(distinct company) where status='active'` |
| 过去 24h 逐条核验过的岗位 | 141,218 | `count(*) where enrich_checked_at > now()-24h` |

岗位卡上的标题 / 公司 / 城市也都是库里真实存在的岗位，不是编的。
**改数字前请重新查库**，别让宣传片里的数字和产品实际能力脱钩。

## 视觉体系

照抄 `app/globals.css` + `DESIGN.md` 的暖纸编辑部体系：
暖纸 `#f4efe6` 底、墨黑 `#1a1714` 作唯一动作色、雷达绿 `#00e676` 只用在扫描扇 / 命中点 /
「仍在招」、状态 chip 用产品里的真实取值、字体走系统栈（不引 webfont）。

⚠️ 竖屏下 `globals.css` 那三层径向渐变里的**冷色那层会铺满上半屏、把暖纸洗成惨白**，
所以这里把冷色压到 .19 并补了一层暖白提亮中心。改背景时注意这一点。

## 已知边界

- **没有声音。** 抖音 / 小红书的实际用法基本都是发布时挂平台的热门音频，
  所以成片交的是无声版；要配乐请在剪辑软件里加（不要让我去找有版权风险的音乐）。
- **只做了 9:16。** `__setSize(w,h)` 对其他画幅是整体等比缩放居中，
  16:9 会剩两条大空边 —— 真要横版需要重新排一次版式，不是改个参数的事。
- 片里的 UI 是**按真实产品重新合成**的，不是真实截屏。版式、文案、配色、
  状态 chip 都对着代码抄的，但**如果产品 UI 改版，这个片子不会自动跟着变**。
